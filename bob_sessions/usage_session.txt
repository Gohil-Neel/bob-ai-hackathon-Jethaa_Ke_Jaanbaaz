========================================================
  SECTION 3 — WHY THIS FILE EXISTS (DEVELOPER NOTE)
========================================================

IBM Bob IDE normally generates session reports and task
history that can be exported from the IDE interface.
However, during this project the developer was UNABLE TO
LOCATE the log/export data through the expected IDE paths.

Possible reasons the log data was not found:
  1. The Bob IDE session was not exported before closing.
  2. The export path differs across operating system versions.
  3. The task history was not persisted in the current workspace.
  4. The IDE version in use may handle logs differently.
