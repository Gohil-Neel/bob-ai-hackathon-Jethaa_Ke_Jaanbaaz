# Bob Sessions

This directory stores IBM Bob IDE task session exports and screenshots.

## Required Contents (for hackathon submission)

- Bob task session reports (exported from IBM Bob IDE)
- Screenshots of Bob task consumption
- Any other Bob usage evidence required by the hackathon guide

## Format

Export Bob task history as reports and place them here.
Screenshots of task consumption should be added here as well.

## Note

Do not include:
- Credentials or API keys
- Personal data
- Sensitive information

This directory will be populated during the project development phases.
